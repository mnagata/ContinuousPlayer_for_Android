# ContinuousPlayer

TVアニメのOP/EDを中心に、フォルダー内の動画・音声を連続再生するAndroidアプリです。スマートフォン・タブレットとAndroid TVで同じAPKを使用します。

## 主な機能

- 選択したファイルから、同じフォルダー直下の動画・音声を連続再生
- ファイル名に応じて `作品 OP → 作品 ED → 作品 OP2 → 作品 ED2` の順に整列
- 端末内のフォルダー（SAF）、TVのUSBストレージ、LAN内のNAS / DLNAサーバーから再生
- SAF・USB・DLNAの保存済みフォルダー一覧と、USBの最後に開いたフォルダーの記憶
- タッチ、TVのD-pad、メディアキーによる再生・一時停止・シーク・前後移動
- ファイル・音声出力情報の表示と、対応USB DACへのビットパーフェクト設定

## 動作環境

- Android 14（API 34）以上のスマートフォン・タブレット・Android TV
- USB再生：端末がUSBメモリーを外部ストレージとして認識していること
- DLNA再生：端末とメディアサーバーが同じLANに接続されていること

ローカル／USBの対応拡張子は `.mp4`、`.m4v`、`.mp3`、`.flac`、`.m4a`、`.aac`、`.wav`、`.ogg`、`.opus` です。実際に再生できるコーデックは端末に依存します。

## 使い方

### スマートフォン・タブレット

1. 起動後に「OP / EDを選ぶ」を押します。
2. 保存済み一覧が表示された場合は「フォルダーを追加」を選び、追加先の「端末 / SAFのフォルダー」から、システムの画面でフォルダーへのアクセスを許可します。
3. アプリ内ブラウザーでフォルダーを開き、再生開始する動画・音声ファイルを選びます。

次回は保存済みフォルダーから選択できます。保存済みがSAFの1件だけの場合は、そのフォルダーを直接開きます。別のフォルダーを追加するには「保存済みフォルダーへ」→「フォルダーを追加」を選びます。

### Android TVのUSB再生

Android TVでも「端末 / SAFのフォルダー」からシステムのフォルダー選択画面を開けます。フォルダーへのアクセスを許可すると保存済み一覧に登録されます。SAFの選択画面を起動できない端末では案内を表示し、USBブラウザーへ進めます。

1. USBメモリーを接続し、「OP / EDを選ぶ」を押します。保存済み一覧が表示された場合は「フォルダーを追加」を選びます。
2. 「USB / 外部ストレージを選ぶ」を選択します。初回は案内から設定を開き、ContinuousPlayerの「すべてのファイルへのアクセス」を許可してアプリへ戻ります。
3. D-padでUSB → フォルダーを開き、「このフォルダーを登録」を押すと保存済み一覧に登録されます。保存済み一覧からフォルダーを開くと、DLNA・SAFと共通のファイル選択画面で再生開始ファイルを選べます。USBブラウザーで直接ファイルを選んで再生することもできます。

USBブラウザーのドライブ一覧・フォルダー一覧も、DLNA・SAFと共通のデザインです。上部の上のフォルダー・キャンセル・再読み込みとアイコン付き一覧で操作し、フォルダー追加時には下部に「このフォルダーを登録」を表示します。

USBブラウザーは読み取り専用です。次回は最後に開いたフォルダーから始まります。USBが見つからない場合は接続と端末側の認識を確認し、「再読み込み」を選びます。

### NAS / DLNA再生

1. NASのDLNAメディアサーバーを起動し、再生したいフォルダーを公開します。Synologyでは「メディアサーバー」と「インデックスサービス」で動画／音楽の対象フォルダーを設定します。
2. 「OP / EDを選ぶ」を押し、保存済み一覧が表示された場合は「フォルダーを追加」を選びます。
3. 「NAS / DLNAから選ぶ」→ サーバー → フォルダー → 再生開始ファイルを選びます。

フォルダー内の「登録」を押すと、次回は保存済み一覧から開けます。登録せずに再生することもできます。

### 保存済みフォルダー

保存済み一覧には、アクセスを許可したSAFフォルダーと登録したUSB・DLNAフォルダーを表示します。項目を長押しして「登録解除」を選ぶと一覧から外せます。フォルダーやファイル自体は削除されません。

SAF・USB・DLNAのファイル選択一覧では、メディアファイル名の拡張子を表示しません。フォルダー名はそのまま表示します。

共通の再生ファイル選択画面では、リモコンのD-pad上下で項目を選び、左で前のページ、右で次のページへ移動できます。決定でフォルダーを開くか、選択したファイルから再生します。

### 再生中の操作

| 操作 | タッチ | リモコン | キーボード（再生領域） |
|---|---|---|---|
| 再生 / 一時停止 | 画面中央1/3をタップ | 決定、再生・一時停止キー | Space / Enter |
| 10秒巻き戻し / 早送り | 画面左 / 右1/3をタップ | ↑ / ↓（D-pad上 / 下）、巻き戻し / 早送りキー | ↑ / ↓、Shift＋← / → |
| 前 / 次のファイル | 右 / 左へスワイプ | ← / →（D-pad左 / 右）、前 / 次キー | ← / → |
| ファイル一覧 | 画面の一覧ボタン | 戻る | Esc / O |
| メディア情報 | 画面の情報ボタン | INFO | I |
| ホームに戻る | 画面のホームボタン | 画面のホームボタン | H |

タップは指を離した時点ですぐに実行します。同じ領域の近い位置に300ms以内に始まった追加タップは実行せず、ダブルタップも1回分の操作になります。距離はOSの許容範囲を使い、OSの判定時間が長い場合はそれに合わせます。

スワイプは指を離した時に判定し、横移動70dp以上・横が縦の1.5倍以上で前後のファイルへ移動します。速度の条件はなく、ゆっくりした操作にも対応します。複数の指を使った操作やキャンセルは曲送りにせず、スワイプをタップとして重複実行しません。

マウス・トラックパッドでは、背景のどこをクリックしても再生／一時停止を切り替えます。近い位置でのダブルクリックは1回分です。ドラッグやホイールで曲送り・シーク・音量変更は行いません。マウスを動かすと操作部を表示し、動画再生中は3秒間操作がなければ操作部とカーソルを隠します。ボタン上や操作部にフォーカスがある間は表示を維持します。一覧はクリックで選択し、ホイールでスクロールできます。保存済みの登録先は右クリックでも登録解除の操作を開けます。

キーボードでも、ボタンにフォーカスがある場合は矢印でボタンを移動し、Enterで選んだボタンを実行します。Tab／Shift＋Tabで部品間を移動できます。文字入力中は文字・空白・削除・カーソル操作を優先します。再生領域のキーを長押ししても、再生切替・曲送り・シークは1回だけ実行します。

音声のみの再生では、再生中もタイトルと操作部を表示します。動画でも、OSのタッチ探索が有効な間は操作部を表示し、読み上げ用のクリックで操作できます。最後まで再生すると「最後まで再生しました」、再生エラーが残っている間はエラーの状態と操作部を表示します。スマホ・TV、端末内・USB・SAF・ネットワークのいずれでも、失敗したファイルで一時停止し、自動で次のファイルへ進みません。ファイル名と理由を案内し、明示操作を待ちます。背景や一覧・情報画面での失敗は、再生画面へ戻ってから案内し、自動再開しません。再生中の中央ボタンは「一時停止」、一時停止・終了・エラー時は「再生」のアイコン・読み上げ名・ツールチップに切り替わります。

一時停止すると、上段に「ホームに戻る」「ファイル一覧」「メディア情報」、独立したファイル名行、下段に「前のファイル」「10秒戻す」「再生」「10秒進める」「次のファイル」を表示します。前後送り・シークの画面ボタンは一時停止を維持して操作できます。先頭／末尾では移動できない前／次ボタンを無効にし、シークできない間は±10秒ボタンも無効にします。「ホームに戻る」は再生を終了し、ホームへ戻ります。「ファイル一覧」は現在の再生セッションを保持して一時停止し、再生元のフォルダーを開いて現在のファイルが見える位置へ移動します。曲送り後はその時点のファイルを対象とし、TV・キーボード操作ではその行にフォーカスを合わせます。キャンセルすると元のファイル・位置・再生／一時停止状態へ戻ります。別のフォルダーへ移動しても、ファイルを選ぶまでは元のプレイリストを維持します。一覧表示中にバックグラウンドへ移った場合や、元のローカルファイルにアクセスできなくなった場合は、キャンセル後も一時停止します。ファイルを選ぶと、同じファイルでも0秒から新しいセッションで再生します。

「メディア情報」、リモコンのINFO、キーボードのIで情報画面を開くと、再生を一時停止します。OK・I・Esc・戻るで情報だけを閉じ、元が再生中なら同じ位置から再開し、元が一時停止ならその状態を保ちます。情報表示中に背景化・音声割り込み・出力切断があった場合や、元のファイルへアクセスできなくなった場合は、閉じた後も手動再開を待ちます。

一覧・情報・エラー画面が前面にある間、ヘッドホン等からの再生・曲送り・シーク・停止操作は背後の再生へ適用しません。一覧・情報を閉じる際は元の再生意図と割り込み状態に従って復帰します。音量は引き続きOS側で操作できます。

スマートフォン・Android TVの戻るキーと、キーボードのEsc／Oは、再生セッションを保持してファイル選択画面を開き、現在のファイルが見える位置へ移動します。連続再生で次のファイルへ進んだ場合は、その時点のファイルを対象とします。一時停止中も同じ動作です。一覧内では戻るキー／Backspaceで親の階層へ移動し、最上位では選択全体をキャンセルします。Page Up／Downは左右キーと同じページ移動です。Escはどの階層でも選択全体をキャンセルします。ホーム画面の戻るはOSの通常動作に従い、アプリを終了する場合は、ホームの「その他」→「アプリを終了」を選びます。再生画面には終了ボタンを置きません。

選択したフォルダー直下のファイルを再生し、最後のファイルで終了します。終了後に再生を操作すると、最後のファイルの0秒から再開します。シーク不可のメディアでは±10秒ボタンを無効にし、タッチ・キー・外部再生コントローラーからのシークも実行しません。前後のファイル選択は引き続き使えます。±10秒は外部コントローラーでも同じ幅で、巻き戻しは0秒で止まり、早送りが末尾以上になる場合は次のファイルの0秒へ移動します。次がなければ位置を変えません。長さ不明の場合は推測で次のファイルへ進みません。バックグラウンドでは一時停止し、アプリへ戻った後や画面消灯からの復帰後も、元のファイル・位置で一時停止を維持します。画面の再生ボタンなどの明示操作で再開します。音声フォーカスの喪失（音量低下要求を含む）や使用中の音声出力機器の切断でも一時停止し、復帰・再接続だけでは再開しません。画面回転や表示中のフォーカス移動だけでは再生／一時停止の状態を変えません。再生位置・履歴の永続保存には対応していません。

## ビルド

開発環境はAndroid Studio、Android SDK 36（minorApiLevel 1）、JDK 21です。Target SDKは36、Java/Kotlinのコンパイル出力はJVM 11です。

```bash
./gradlew assembleDebug
```

生成APKは `app/build/outputs/apk/debug/app-debug.apk` です。Android StudioのRun、またはAPKの更新インストールで端末へ反映します。

画面・並び順・エラー処理・音声出力・実装構成・テストの詳細は [アプリケーション仕様書](docs/spec.md) を参照してください。
