# ContinuousPlayer

TVアニメのOP/EDを中心に、フォルダー内の動画・音声を連続再生するAndroidアプリです。スマートフォン・タブレットとAndroid TVで同じAPKを使用します。

実装照合日：2026-09-28。未コミットの実装を含む現在の作業ツリーに基づきます。

## 主な機能

- 選択したファイルから、同じフォルダー直下のメディアを連続再生
- ファイル名に応じたOP/EDの並び替え
- スマートフォンのタッチ操作とTVのD-pad・メディアキー操作
- スマートフォンではSAFでフォルダーへのアクセスを許可し、DLNAと共通デザインのアプリ内ブラウザーでファイルを選択。TVではアプリ内USBブラウザーを使用
- Synologyメディアサーバーなど、LAN内のDLNAサーバーを検出して動画・音声を連続再生
- SAF・DLNAの保存済みフォルダー一覧、DLNAの登録・登録解除、再生元フォルダーへの戻り操作
- アイコンと配色を統一した初期画面、SplashScreen APIによる起動画面
- ファイル・音声出力情報の表示と、対応USB DACへのビットパーフェクト設定
- TVでの再生エラー詳細表示

## 動作環境

- Android 14（API 34）以上。TVも同じ最低OSバージョンが必要です。
- Compile SDK：36（minorApiLevel 1）、Target SDK：36
- USB再生には、端末がUSBメモリーを外部ストレージとして認識している必要があります。
- 再生できる動画・音声コーデックは端末に依存します。

## 起動とファイル選択

起動後は、濃紺・シアン・紫を基調とした初期画面を表示します。ロゴ、アプリ名、「ANIME OPENINGS / ENDINGS」、「OP / EDを選ぶ」、Exitを配置し、キャッチコピーは表示しません。横画面用の寸法とスクロールに対応しています。

スプラッシュはアイコンの前景と濃紺背景を使用します。TV以外では終了時に180msでフェードアウトし、TVはシステムの起動演出に従います。

### スマートフォン・タブレット

1. 「OP / EDを選ぶ」を押します。
2. 保存済みフォルダーがなければ再生元を選び、「端末 / SAFのフォルダー」からSAFの画面でフォルダーを選びます。
3. DLNAと同じデザインのアプリ内ブラウザーで、サブフォルダーを開き、再生開始する動画または音声ファイルを選びます。
4. 同じフォルダー直下の対応ファイルをOP/ED順で表示し、選択位置から連続再生します。

読み取り権限がある場合はアプリ内ブラウザーから始まります。DLNAの登録がある場合や複数のSAFフォルダーがある場合は保存済み一覧を表示し、SAFの1件だけなら直接開きます。ルートの「保存済みフォルダーへ」から「フォルダーを追加」で端末 / SAFまたはNAS / DLNAを選べます。ファイル選択にシステムのSAFピッカーは使いません。SAFの登録済みフォルダー一覧とフォルダー内の並び順は、DLNAと同じ年の昇順・冬→春→夏→秋の季節順です。動画・音声はUSB・DLNAと共通のOP/ED順です。SAFのフォルダー選択画面を起動できない場合はUSBブラウザーへ進みます。

保存済み一覧ではSAFを先に季節順で表示し、続いてDLNAの登録をサーバー名＋フォルダー名の順で表示します。システムのフォルダー選択をキャンセルすると追加先選択へ戻ります。永続アクセス許可を保存できなかった場合は通知し、次回はフォルダーを選び直します。クラウド側の一覧取得が途中の場合は再試行を案内し、部分的なプレイリストで再生を始めません。

### Android TV・Nebula X1のUSB再生

TVではシステムのSAFピッカーに依存せず、アプリ内USBブラウザーを使用します。DLNAの登録がある場合は「OP / EDを選ぶ」で保存済み一覧を表示します。一覧の「フォルダーを追加」からUSBまたはDLNAを選べます。

1. USBメモリーを接続し、「OP / EDを選ぶ」を押します。
2. 保存済みフォルダーがなければ、追加先で「USB / 外部ストレージを選ぶ」を選択します。初回は説明から設定を開き、ContinuousPlayerの「すべてのファイルへのアクセス」を許可します。
3. 戻るボタンでアプリへ戻ります。
4. USB / 外部ストレージ → フォルダー → 再生開始ファイルを選びます。

この許可は共有ストレージ全体への読み書きを可能にしますが、アプリのUSBブラウザーは読み取りのみを行います。許可しない場合、USBブラウザーでの選択はできません。

- フォルダーとファイルをD-padで選択できます。
- 最後に開いたフォルダーを記憶し、再表示時やアプリ再起動後もそこから開きます。USBが未接続、フォルダーが削除済み、または読み取れない場合はストレージ一覧を表示します。
- USBの閲覧位置はSAF・DLNAの保存済み一覧には登録しません。
- 「上の階層へ」または戻るキーで親へ移動し、ドライブのルートからはストレージ一覧へ戻ります。
- 親へ戻ると、直前に開いていた子フォルダーへカーソルとスクロール位置を戻します。ストレージ一覧へ戻る場合は元のUSBを選択します。対象がなくなった場合は先頭行を選択します。
- 「キャンセル」でブラウザーを閉じます。
- USBが見つからない場合は、接続・端末側の認識を確認して「再読み込み」を選びます。
- 許可画面を開けない場合は、アプリの案内に従って端末設定から許可してください。

Android TV OSのバージョンだけでは、SAFのファイル選択画面が利用できるとは限りません。現在のTV向け実装はUSBブラウザーを使用します。Nebula X1での修正後の再生成功は、まだ実機確認されていません。

## NAS / DLNA再生（Synologyメディアサーバー）

1. Android端末とNASを同じLANに接続します。TVの有線LANも利用できます。
2. Synologyのパッケージセンターで「メディアサーバー」をインストール・起動します。
3. DSMの「インデックスサービス」で対象フォルダーを動画／音楽のインデックス対象に追加し、インデックス作成を待ちます。
4. アプリの「OP / EDを選ぶ」で保存済み一覧が表示されたら「フォルダーを追加」を押し、追加先の「NAS / DLNAから選ぶ」からNAS → 動画／音楽 → フォルダーへ進み、再生開始ファイルを選択します。保存済みフォルダーがない場合は追加先選択から始まります。サーバーの設定により階層名は異なります。
5. 同じDLNAフォルダー直下の動画・音声を、USB・SAFと共通のOP/ED順で連続再生します。

DLNAのフォルダーを開いて「登録」を押すと、SAFの許可済みフォルダーと同じ「保存済みフォルダー」一覧に登録します。次回は「OP / EDを選ぶ」から登録先へ直接進めます。登録先のサーバーは開くたびに検索し、サーバーID（通常はUDN）で照合するため、IPアドレスの変更に対応します。DLNAではSAFのアクセス権は取得せず、サーバーID・フォルダーID・辿った階層を保存します。DLNAの登録解除はフォルダー内の「登録解除」、または保存済み一覧の項目を長押しして行います。SAFも保存済み一覧で長押しして「登録解除」を選ぶと、保存したアクセス許可を解放して一覧から除外します。フォルダーやファイル自体は削除しません。SAFの1件だけが直接開いた場合は「保存済みフォルダーへ」で一覧に戻れます。オフラインでも一覧から登録解除できます。サーバーIDやフォルダーIDが変わった場合は登録し直してください。

登録は任意で、未登録のフォルダーからも再生できます。サーバーがUDNを返さない場合は検出時のアドレスをIDに使うため、IP変更後に登録し直す必要があります。

タッチとTVのD-padに対応します。画面の大きさに合わせた専用ダイアログに、現在の階層と件数、種類別アイコン、20sp・最大2行の名前を表示します。フォルダー・ファイルの各行は名前のみとし、名前の下にあった操作説明やサイズ表示を省いて最小高さ56dpにしています。選択行はシアンの太い枠で強調します。初期選択は先頭項目で、親へ戻った際は直前の子フォルダーを表示・選択します。横画面では親移動ボタンをタイトル横へ配置し、操作ヒントを省いて一覧の領域を確保します。回転時は選択位置を維持し、外側をタップしても閉じません。

一覧から独立した「上の階層へ」ボタンまたは戻るキーで親へ移動し、通常のサーバー探索から開いた場合はルートからサーバー一覧へ戻ります。保存済み登録や再生元から開いた場合はルートから保存済み一覧へ戻ります。「閉じる」はブラウザーを閉じ、「再読み込み」は現在の一覧を取得し直します。空フォルダーや通信エラーの案内もダイアログ内に表示します。DLNAの読み込み中に戻るキーを押すとブラウザーを閉じます。再生中の「フォルダー選択」は、現在のプレイリストを選んだフォルダーを直接開きます（SAF・USB・DLNA共通）。この再生元情報は画面再生成後も保持しますが、プロセス終了後には復元しません。

フォルダー移動・読み込み・エラー・親へ戻る際や、保存済み一覧から「フォルダーを追加」を開く際は、同じダイアログの内容を更新し、トップ画面が一瞬見える切り替えを防ぎます。追加先選択から戻ると保存済み一覧に戻ります。トップ画面の選択ボタンは「OP / EDを選ぶ」に統一しています。

この共通ダイアログはSAF・DLNAで使用します。USBブラウザーは別の標準ダイアログで、読み込みごとに表示を切り替えます。

DLNAの季節フォルダーは、同じシリーズ名ごとに年の昇順、各年は「冬 → 春 → 夏 → 秋」で整列します。例えば `アニメOPED 2024秋 → アニメOPED 2025冬 → アニメOPED 2025春 → アニメOPED 2025夏 → アニメOPED 2025秋 → アニメOPED 2026冬` です。「2025年冬」や「202501年冬」、季節を `*秋*` と囲む表記にも対応します。その他のフォルダーは名前順を維持し、NAS上の名前は変更しません。

- SSDP探索、UPnP ContentDirectoryのBrowse、HTTP(S)配信を使用します。大きな一覧はページ分割して取得します。
- DLNA一覧は物理フォルダーではなく、サーバーが公開する階層です。サブフォルダーの再帰再生はしません。
- DLNAでは拡張子のないタイトル・URLにも対応し、HTTPで配信される音声／動画のMIME情報を使います。写真、非HTTPリソース、`._`で始まる項目は除外します。再生可能なコーデックは端末とMedia3に依存します。
- サーバーが複数の配信リソースを返す場合、変換済みと明示されていないリソースを優先します。シークやサイズ取得の可否はサーバーに依存し、サイズ情報がなければ「サイズ不明」を表示します。
- DLNAの再生エラーはスマートフォンでも表示し、「再試行」「別のファイルを選ぶ」を選べます。
- NASが見つからない場合は、NASのファイアウォール、メディアサーバーのDMA互換性／デバイス許可、Wi-Fiの端末間通信制限を確認してください。
- DLNAはNASが公開したメディアを参照します。DSMアカウントでのログイン、SMB共有、DTCP-IP保護付き録画、外部レンダラーへのキャストには対応していません。DLNAブラウザーの位置は永続保存しません。
- LAN内のDLNA配信に必要な平文HTTPをネットワークセキュリティ設定で許可しています。通信は暗号化されません。

Synology実機での検出・再生・シークは未確認です。設定の参考：[Synologyのメディアサーバー設定](https://kb.synology.com/en-us/DSM/help/MediaServer/application_mediaserver_general?version=7)。

## 対象ファイルと再生順

ローカル／USBの対応拡張子：

`.mp4` / `.m4v` / `.mp3` / `.flac` / `.m4a` / `.aac` / `.wav` / `.ogg` / `.opus`

- 大文字小文字を区別しません。
- 対象はフォルダー直下の通常ファイルです。サブフォルダーの再帰スキャンは行いません。
- macOSが作る `._作品 OP.mp4` など、名前が `._` から始まるメタデータファイルは、USB・SAF共通で一覧とプレイリストから除外します。USB内のファイル自体は削除しません。
- 通常の隠しファイルは、対応拡張子なら対象です。

基本は端末のロケールに従う名前順です。拡張子を除いた名前が「作品名＋空白＋OPまたはED＋任意の番号」に一致する場合、同じ作品の該当ファイルを次の順に並べ替えます。

```text
作品 OP → 作品 ED → 作品 OP2 → 作品 ED2 → 作品 OP3 → 作品 ED3
```

番号省略は1として扱います。該当ファイル同士の位置だけを入れ替え、それ以外のファイル位置は維持します。本編をOPとEDの間へ挿入する機能はありません。

最終ファイルで再生が終了します。リピート・クロスフェードは実装していません。

## タッチ操作

| ジェスチャー | 動作 |
|---|---|
| シングル / ダブルタップ：左1/3 | 10秒巻き戻し |
| シングル / ダブルタップ：中央1/3 | 再生 / 一時停止 |
| シングル / ダブルタップ：右1/3 | 10秒早送り |
| 右フリング | 前のファイル |
| 左フリング | 次のファイル |

巻き戻しは先頭までです。早送りで末尾に達すると次のファイルへ進み、次がなければ何もしません。

## リモコン操作

| キー | 再生画面の操作 |
|---|---|
| 決定 / Enter / A | 再生 / 一時停止。ツールバーにフォーカスがあれば選択したボタンを実行 |
| D-pad左 / 右 | 10秒巻き戻し / 早送り。ツールバーにフォーカスがあれば項目間を移動 |
| D-pad上 / 下、前 / 次キー | 前 / 次のファイル |
| 再生・一時停止キー | 再生 / 一時停止の切り替え |
| 再生キー / 一時停止キー | 明示的に再生 / 一時停止 |
| 巻き戻し / 早送りキー | 10秒シーク。ツールバーにフォーカスがある場合は標準キー処理 |
| INFO | 情報ダイアログ |
| 戻る | 再生を終了して初期画面へ。初期画面ではOS標準の戻る処理 |

TVではフォーカス表示を行い、初期画面の選択ボタン、ユーザーによる一時停止時の再生再開ボタンへフォーカスを設定します。音量キーはシステム標準の操作です。

## 再生画面と情報表示

再生画面は全画面表示で、Media3標準の操作パネルは使用しません。縦画面ではファイル名・サイズ・コーデック・解像度・音声形式などを下部に表示します。

ユーザーが一時停止した場合に、上部にファイル名と次の4ボタンを表示します。ファイル切り替え・シーク・バッファリング・自然な再生終了だけでは表示しません。一時停止中のファイル切り替えでは表示を維持し、ファイル名を更新します。

- **再生再開** — 再生を再開
- **情報** — ファイル名と音声出力・ミキサー情報を表示
- **フォルダー選択** — 再生を終了し、現在のフォルダーから別のファイルを選択
- **終了（×）** — アプリを終了

アプリがバックグラウンドに移ると一時停止し、再生画面へ復帰すると再開します。バックグラウンド再生サービス、再生位置・履歴の永続保存はありません。

復帰時はバックグラウンド移行前の手動一時停止を区別せず再生します。通常の画面回転はActivity自身で処理しますが、Activityが再生成された場合の再生継続は保証しません。保存済みフォルダーとUSB閲覧位置の保存は、再生位置の保存とは別です。

## 再生エラーとUSB読み取り

- TVまたはDLNA再生ではエラー時に自動スキップせず、一時停止してファイル名・エラーコード・原因を表示します。「再試行」「別のファイルを選ぶ」「キャンセル」を選択できます。「別のファイルを選ぶ」は再生元フォルダーを開き、「キャンセル」はエラーダイアログだけを閉じます。
- TV以外のローカル再生では、次の項目があれば自動スキップします。ただし、エラーカウント3回到達時や末尾ではスキップしません。カウントは成功再生ではリセットされないため、連続エラーのみを数える仕様ではありません。
- USBファイルの選択時には、実際にファイルを開いて先頭・末尾の読み取りを確認します。これは動画形式の再生可否を保証する検査ではありません。
- USB未接続、空フォルダー、権限拒否、読み取り失敗には案内を表示します。

`ERROR_CODE_PARSING_CONTAINER_UNSUPPORTED (3003)` は、プレイヤーがファイルのコンテナー形式を解析できなかったことを示します。`._`付きメタデータの混入は除外対応済みですが、動画本体で同じエラーが出る場合は別途調査が必要です。

## USB DAC音声出力

対応USB DACに対して、AndroidのAudioMixerAttributesを使いBIT_PERFECT設定を試みます。開始ファイルのサンプルレート・チャンネル数に一致する設定を優先し、一致しなければ最初の対応設定を使用します。

設定は再生開始時に非同期で行い、完了を待たずに再生を開始します。曲ごとの再設定やUSB接続変更時の自動再設定はありません。画面上のBit-Perfect表示は設定成功状態であり、実出力のビット一致を測定した結果ではありません。非対応機器やHDMIを含むすべての出力経路での動作は保証しません。

音声出力名は接続済みUSB・Bluetooth・有線機器の一覧から選んだ表示です。実際の再生経路を測定したものではありません。

## ビルドと検証

Gradle DaemonのJDKは21、Java/Kotlinのコンパイル出力はJVM 11です。

```bash
# デバッグAPK
./gradlew assembleDebug

# ユニットテスト
./gradlew testDebugUnitTest

# Android Lint
./gradlew lintDebug

# デバイス / エミュレーターが必要なテスト
./gradlew connectedAndroidTest

# リリースビルド
./gradlew assembleRelease
```

デバッグAPK：`app/build/outputs/apk/debug/app-debug.apk`

端末への反映にはAndroid StudioのRun、または生成APKの更新インストールが必要です。ビルドだけでは端末のアプリは更新されません。リリース署名は別途設定してください。

既存テストには、対応ファイル判定、季節順、DLNAプロトコルとページ分割、SAFの不透明なdocument ID・部分一覧・権限エラーの確認があります。共通ダイアログのAndroidテストではSAF表示・登録ボタンの縦横レイアウト、D-pad、ウィンドウ維持と初回表示サイズも対象です。保存済みDLNAのテストでは永続化・重複防止・一覧からの選択・オフライン登録解除・模擬クライアントのIP／URL変更後の再接続を確認します。`PlaybackFolderTest` はActivity再生成後にUSBの再生元フォルダーを開く操作を対象とします。

このドキュメント更新ではビルド・テストを実行していません。テストの実装内容と成功結果、Nebula X1やSynologyの実機検証は区別してください。

全ファイルアクセス権限を含むため、Google Playでの配布時はその権限の公開要件を別途確認する必要があります。

app/src/main/java/jp/nagu/continuousplayer/
├── MainActivity.kt            # 画面、スプラッシュ、入力、選択フロー
